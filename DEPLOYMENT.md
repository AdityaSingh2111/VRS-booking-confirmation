# 🌐 Deployment Guide

This guide covers building, hosting, and deploying the Booking Confirmation Generator to production environments.

---

## ⚙️ Environment & Node Runtime Requirements

| Requirement          | Specification                   |
| :------------------- | :------------------------------ |
| **Node.js Engine**   | `>=22 <25`                      |
| **Package Manager**  | `npm` (v9+) / `bun` / `pnpm`    |
| **Build Command**    | `npm run build`                 |
| **Output Directory** | `.output/` (generated by Nitro) |

---

## 📦 Build Artifacts Overview

When `npm run build` executes, Vite and Nitro generate production-ready artifacts in `.output/`:

```
.output/
├── public/                # Static assets, compiled CSS & JS bundles (CDN ready)
├── server/                # SSR engine & Nitro server entrypoint (Node.js runtime)
└── nitro.json             # Deployment manifest
```

---

## 🚀 Deployment Targets

### Option 1: Vercel (Recommended)

Vercel automatically detects TanStack Start & Nitro build outputs.

#### Via Vercel Dashboard:

1. Push your repository to GitHub / GitLab.
2. Open [Vercel Dashboard](https://vercel.com/new) and import the repository.
3. Keep default settings:
   - **Framework Preset**: TanStack Start / Nitro (Auto-detected)
   - **Build Command**: `npm run build`
   - **Output Directory**: `.output`
4. Click **Deploy**.

#### Via Vercel CLI:

```bash
# Install Vercel CLI & deploy
npx vercel --prod
```

---

### Option 2: Node.js Production Server

To run the application as a standalone Node.js server (e.g., Docker, AWS EC2, DigitalOcean):

```bash
# 1. Build production bundles
npm run build

# 2. Start Node server entrypoint
node .output/server/index.mjs
```

> **Environment Variables**:
> Set `PORT` (default: `3000`) and `HOST` (default: `0.0.0.0`) in your server environment if needed.

---

### Option 3: Cloudflare Pages / Netlify

Nitro supports multi-preset target builds. To target Cloudflare or Netlify specifically:

```bash
# Cloudflare Pages build
NITRO_PRESET=cloudflare-pages npm run build

# Netlify build
NITRO_PRESET=netlify npm run build
```

---

## 📋 Production Verification Checklist

Before publishing to live domain:

- [ ] Production build succeeds cleanly via `npm run build`.
- [ ] TypeScript & ESLint pass without warnings via `npm run check`.
- [ ] HTTPS / SSL certificate is active on domain.
- [ ] Form submission generates full 2-page PDF document without 404 or asset loading errors.
- [ ] Document print dialog (`Ctrl+P` / `Cmd+P`) opens cleanly and formats within A4 portrait paper bounds.
